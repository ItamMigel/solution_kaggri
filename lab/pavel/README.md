## Как пересобрать BC-агента с защитой
```
python lab/pavel/bc3/export3.py --ckpt bc3_runs/multi15_s0/best.pt,bc3_runs/multi15_s1/best.pt --out base.py --fill --team mgoose_cn
python - <<'PY'   # вставить защиту с окном 13 дней
layer = open("lab/pavel/hg/hg_layer_v2.py").read()
orig = "_HG = {'on': True, 'slack': 3,"
open("main.py", "w").write(open("base.py").read() + layer.replace(orig, "_HG = {'on': True, 'active_last_day': 13, 'slack': 3,"))
PY
```
Упаковка и проверка архива: `scripts/package_candidate.sh <main.py> <имя>`.

## Инструменты
- `opp_ident.py` — узнаёт агента соперника по записанным ходам (подаёт наблюдения известным агентам).
- `diff_actions.py` — пошаговые отличия действий соперника от эталонного агента.
- `replay_eval.py` — кандидат в записанном ладдерном мире против записанных действий соперника.
- `vs_top.py` — то же против записанных игр топ-команд.
- `tapes/trade_audit.py`, `tapes/trade_steps.py` — точное воспроизведение игр с журналом сделок движка.
- `tapes/extract_tapes.py`, `tapes/tape_eval.py` — ленты топ-команд и их проигрывание против живых агентов.
- `bc3/` — обучение/экспорт BC, `bc3/gate.py` — шлюз оценки; `hg/` — защита стада.
- `fetch_subs.py` — скачивание реплеев своих сабмитов; `ladder_summary.py` — сводка ладдера по классам соперников.
