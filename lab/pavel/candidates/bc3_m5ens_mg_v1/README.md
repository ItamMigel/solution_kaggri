## Что это
Ансамбль двух моделей BC v3 (сиды 0 и 1), обученных на 576 реплеях пяти наборов: Mother-Goose (основная версия 56525914
и вторая 56538672), DECEM, M&M&P&Q, Boey, с меткой команды. Агент играет от имени Mother-Goose. Декодирование: жадное,
заполнитель простоя для юнитов с запрещённым лучшим действием. Только numpy + стандартная библиотека, веса встроены
(float16), файл ничего не читает с диска. Собран `solution/lab/pavel/bc3/export3.py` (ветка pavel-lab).
