# bc_hg_m26dsm_d13_tl — bc_hg_m26dsm_d13 + финальная распродажа (TL)

Исправляет баг, найденный Адилем: BC-агенты заканчивали игру с непроданным товаром. На ладдере в среднем $438–557
за игру (медиана ~$190, максимум ~$5.3k), у соперников ~$60: в руках работников пшеница/морковь (последний день игра
кончается раньше авто-сдачи в конце дня), на складе шерсть, удобрение, яйца, томаты.
Слой `runs/agents/tl/tl_layer.py` (обёртка поверх HG): с шага 690 работник с товаром идёт к складу и сдаёт его, только
если иначе не успеет (оставшиеся ходы ≤ расстояние + 1); в последние 3 хода не берёт товар со склада; с шага 712
продаёт склад равными долями; на шаге 718 продаёт всё (склад + сданное в этот же ход).
